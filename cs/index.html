저장된 비밀번호 없음

간단 비밀번호를 넣으면 시트가 확인한 뒤 긴 키를 이 기기 브라우저에만 저장합니다. 5번 틀리면 15분 잠김. 공용 PC에서는 다 쓰고 [지우기]를 눌러 주세요.

💻 다른 PC 에서 메신저 쓰기 (집 PC·직원 PC — 여러 대 가능)

메신저 창 붙이기·보내기·거래처 사진적용만 쓰는 PC입니다. 수집·등록·로그인은 하지 않고 시트 요청도 가져가지 않습니다 (그건 마스터 PC 한 대가 함 — 사무실 PC가 켜져 있으면 됨).

⬇ 메신저 도우미 설치 파일 (.bat) ▶ 창 도우미 켜기
  1. 받은 msn_helper.bat 더블클릭 (「Windows의 PC 보호」 창 → 추가 정보 → 실행) — 파이썬이 없으면 설치 안내가 뜸
  2. C:\SystemV3 에 설치되고 검은 창 없이 뒤에서 켜짐 · 바탕화면 V3 Messenger Helper 아이콘 · 컴퓨터 켤 때 자동 시작
  3. 💬 메신저 / 📦 거래처 탭 → 🪄 창 도우미 연결하기 → 크롬이 물으면 [허용] (처음 한 번)
  4. 꺼져 있으면 [▶ 창 도우미 켜기] (크롬이 물으면 [열기]) · 끄기: C:\SystemV3\msn_helper.bat stop

⚠ 다른 PC 에서는 아래 마스터 PC 설정(설치 파일·원터치 설정·웹연결)을 하지 마세요.

🖥 마스터 PC 설정 (수집기 PC — 사무실 PC 한 대만)

수집·등록·로그인을 맡는 PC는 한 대만 둡니다. 두 대가 켜지면 요청을 나눠 가져가고, 메이크샵은 같은 계정 동시 로그인이 안 돼서 서로 로그아웃시킵니다. 다른 PC에서는 위의 💻 다른 PC 에서 메신저 쓰기만 하세요.

💾 마스터 PC 설치 파일 (사무실 수집기 PC 한 대만 · Windows 전용)
⬇ ① 설치 시작 파일 (.bat) ⬇ 파이썬 3.14 (Windows 64비트) 📁 수집기 폴더 (드라이브)
  1. ① 설치 시작 파일을 받아 더블클릭 (「Windows의 PC 보호」 창 → 추가 정보 → 실행)
  2. 구글 드라이브 데스크톱이 없으면 자동 설치 → w.works.official@gmail.com 으로 로그인 → 공유 문서함 2_CS_게시판_정리 우클릭 → 바로가기 추가 → 내 드라이브
  3. 폴더가 내려오면 ▶G1수집기_1_설치(처음한번).bat 이 저절로 실행 — 파이썬·부품까지 자동 설치 (검은 창은 끝날 때까지 두기)
